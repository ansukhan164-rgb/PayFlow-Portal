# 💼PayFlow-Portal
PayFlow is a Employee Payroll &amp; Leave Management System is a full-stack HR automation platform that streamlines employee records, attendance, payroll processing, leave management, payslip generation, and reporting, helping organizations reduce HR workload, improve accuracy, and increase operational efficiency.

scre
### Employee Payroll and Leave Management System

PayFlow Portal is a modern web-based Employee Payroll and Leave Management System designed to streamline HR operations, automate payroll processing, and simplify employee leave tracking. The platform reduces manual workload, improves payroll accuracy, and provides a centralized solution for employee management.

---

## 🚀 Features

### 👨‍💼 Employee Management

* Add, update, and delete employee records
* Manage employee profiles and departments
* Search and filter employees

### 💰 Payroll Management

* Automated salary calculation
* Generate monthly payroll records
* Salary breakdown with allowances and deductions
* Payroll history tracking

### 🏖️ Leave Management

* Apply for leave online
* Leave approval/rejection workflow
* Track leave balances
* Leave history management

### 📊 Dashboard & Analytics

* HR dashboard with key statistics
* Employee count overview
* Payroll summaries
* Leave status reports

### 🔐 Authentication & Security

* Secure login system
* Role-based access control
* Protected routes and data access
* Session management

### 📱 Responsive Design

* Mobile-friendly interface
* Tablet and desktop support
* Modern and intuitive UI

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/ansukhan164-rgb/PayFlow-Portal.git
```

### Navigate to Project

```bash
cd PayFlow-Portal
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```
